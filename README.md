# ChartsGS6
A GitHub repository that contains custom & original charts made specially for offline rhythm game GridlessSekai6

# Credits

Most of the charts arent mine! They're downloaded and compiled into a .gs6 file!

All of the chart credits go to the creators of them!

Keep in mind that the chart can have:
- Missing notes
- Music can be delayed/earlier
- Not included MV
- Only 1 difficulty (mostly master/expert)

If you run into any issue with any chart, please file a issue!
